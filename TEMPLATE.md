# 42 Project Template

Use this repository as a template for a new 42 project.

The Makefile provides repository, project, issue, branch, label, and pull-request workflows backed by GitHub CLI.

## Quick start

```bash
make setup-gh
make repo
```

`make repo` creates a repository from `Lucas-pin/42-project-template` and can optionally clone it. Customize the copied Makefile and scripts for the project's language and build system.
